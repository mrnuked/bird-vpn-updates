# Bird VPN 0.4.6

## Что исправлено

- устранена циклическая DNS-зависимость при подключении к VLESS-серверу с доменным адресом;
- домен выбранного сервера разрешается до создания TUN-интерфейса;
- весь полученный пул IPv4/IPv6 передаётся Xray через локальную таблицу `hosts`;
- исходный домен сохраняется в конфигурации для корректной работы REALITY/SNI;
- при повторном подключении порядок резервных IP меняется;
- при временной недоступности DNS используется сохранённый пул адресов;
- если домен невозможно разрешить и сохранённых адресов нет, текущее рабочее
  соединение не отключается;
- пользовательские DNS-запросы по-прежнему перехватываются внутри TUN и
  направляются через защищённый DoH по VLESS-туннелю;
- серверы, заданные готовым IP-адресом, включая SMART Auto, работают без
  дополнительного DNS-bootstrap.

## Совместимость

Настройки, подписки и серверы Bird VPN 0.4.5 сохраняются. Установка поверх
предыдущей версии поддерживается.
